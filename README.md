# AI Chat Bot

A full-stack AI Chat Bot built with the MERN Stack and Google Gemini AI. The application provides real-time AI response streaming, conversation management, authentication, markdown rendering, syntax-highlighted code blocks, and modern chat features similar to ChatGPT.

## Features

### Authentication & Authorization

* User Registration
* User Login
* JWT Authentication
* HTTP-Only Cookie Based Authentication
* Protected Routes
* Logout Functionality

### Conversation Management

* Create New Conversations
* View All Conversations
* Rename Conversations
* Delete Conversations
* Search Conversations
* Conversation Ownership Protection

### AI Chat Features

* Google Gemini AI Integration
* Real-Time Response Streaming
* Stop Generation Feature
* Partial Response Saving
* Typing Indicator
* Auto Scroll to Latest Message

### Message Features

* Send Messages
* Fetch Conversation Messages
* Markdown Rendering
* Code Block Rendering
* Syntax Highlighting
* Copy Code Button
* Copy Entire Message Button

### Security Features

* Password Hashing using bcrypt
* JWT Authentication
* HTTP-Only Cookies
* Rate Limiting
* XSS Protection
* Protected API Endpoints

## Tech Stack

### Frontend

* React.js
* Redux Toolkit
* React Router DOM
* Tailwind CSS
* React Markdown
* React Syntax Highlighter

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt

### AI

* Google Gemini API
